## 📥 Descargar la última versión

Ve a la pestaña **Releases** y descarga `MultiCartera-Setup-vX.Y.Z.exe`.

## 🔧 Instalación

1. **Descarga** el instalador `.exe`.
2. Ejecútalo (doble clic). Si SmartScreen advierte *"Windows protegió tu PC"*,
   pulsa **Más información → Ejecar de todas formas** (la app no está en la
   tienda de Microsoft, es normal en software nuevo sin certificado EV).
3. Sigue el asistente (español/inglés) e instala.
4. Abre **MultiCartera** desde el menú de inicio.

> 💡 Requisitos: Windows 10/11 de 64 bits y conexión a internet.

## 🔄 Actualizaciones

- Dentro de la app: módulo **Actualizaciones** → comprueba y descarga el nuevo instalador.
- Manual: descarga el nuevo `.exe` de este repo e instala encima.
